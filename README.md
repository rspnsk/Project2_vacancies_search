# Проект "Приложение по поиску вакансий посредством сайта HH.ru"

## Описание: 
Это приложение представляет собой инструмент для работы с вакансиями на платформе hh.ru. Оно позволяет получать информацию о вакансиях, сохранять её в файл, а также работать с этим файлом и фильтровать его.

### Описание модулей:
Список вакансий хранится в JSON-файле в модуле data. 
В пакете src находятся модули со следующими функциями:
- в модуле hh_api.py, для работы с hh.ru, реализован абстрактный класс AbstractAPI и класс HeadHunterAPI,
который подключается к API hh.ru и получает вакансии согласно заданным параметрам.
- в модуле vacancies.py реализован класс Vacancy для работы с вакансиями. 
В данном классе определены следующие атрибуты: название, ссылка, зарплата и описание вакансии. 
Поддерживает методы сравнения вакансий по зарплате и валидацию данных.
- В модуле json_saver.py реализован абстрактный класс JsonSaveAbstract, 
который определяет интерфейс для работы с вакансиями, а также создан класс JSONSave, 
наследованный от абстрактного класса, для сохранения информации о вакансиях в JSON-файл.

В модуле main создана функция user_interface для взаимодействия с пользователем через консоль. 
Пользователь получает данные по вакансиям согласно запросу. 

Установка
Клонируйте репозиторий git clone https://github.com/rspnsk/Project2_vacancies_search/
Установите зависимости poetry install
Конфигурационные файлы. В проекте есть файлы конфигурации, в которых находятся переменные для записи в них путей к файлам и других параметров.
Тестирование.
Проект покрыт юнит-тестами Pytest. Чтобы запустить тесты с оценкой покрытия выполните команду: pytest
Тесты находятся в папке tests
